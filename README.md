# E-Commerce Sales Analysis Dashboard

## Project Overview

This project is an E-Commerce Sales Analysis Dashboard created using Microsoft Excel.

The project covers data cleaning, data transformation, Pivot Tables, and dashboard creation.

## Project Workflow

Raw Data
→ Power Query Data Cleaning
→ Data Transformation
→ Pivot Tables
→ Excel Dashboard

## Sheets Included

- Customers
- Orders
- Products
- DATA
- Pivot Table
- Dashboard

## Dashboard KPIs

- Total Revenue
- Total Orders
- Average Quantity
- Average Delivery Days
- Average Spending

## Analysis

The dashboard provides insights into:

- Monthly sales trends
- Product performance
- City-wise quantity
- Occasion-wise sales
- Category-wise sales
- Customer and order patterns

## Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Excel Dashboard
- Data Cleaning
- Data Visualization

## Project File

The complete Excel workbook contains the cleaned data, Pivot Tables, Power Query work, and final interactive dashboard.
